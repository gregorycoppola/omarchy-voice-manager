# Intent definitions moved

The independent [public intent dataset](https://github.com/gregorycoppola/omarchy-voice-dataset)
is the source of truth for shared intent schemas, examples, grammar, and provider
bindings. Its `data/history/2026-09-24/` retains the earlier 55-intent research audit.
The obsolete local copies have been removed to avoid competing definitions.

See [data ownership and personal overrides](../data-ownership.md) for the runtime
connection, private SQLite migration, precedence, and installation details.
